# Source and maintenance

Ammo Agent Usage continues the Ammo project, originally developed as
`agent-remain-island`. Copyright 2026 Ammo contributors. The Apache-2.0 license,
NOTICE and applicable third-party notices are retained.

This repository starts with a reviewed snapshot of the current source and an
independent Git history. Previous development history, local account data,
signing configuration, design exports and private release evidence are excluded.
New development belongs in this repository.

`project.yml` generates the Apple project with XcodeGen. Package.resolved,
package-lock.json and scripts/requirements.lock.txt record dependencies.
Synthetic contracts and tests remain part of the source distribution.
