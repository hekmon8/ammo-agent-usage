Inter Tight variable font (weights 100–900), from Google Fonts:
https://github.com/google/fonts/tree/main/ofl/intertight

Source file: InterTight[wght].ttf; bundled without modification as InterTight.ttf.
License: SIL Open Font License 1.1, included in OFL.txt.
Latin text uses Inter Tight; unsupported characters use native font fallback.
Workspace headings use negative tracking, including section headings (-0.6),
following the final instruction in the supplied visual specification.
SwiftUI lineSpacing adds leading without clipping fallback glyphs or Dynamic Type.
